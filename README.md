# ✨ PDF Vibe Watermarker

> A modern, local-first web application to add professional watermarks to your PDF documents. Built with Python & Streamlit.

## 🌟 Features
*   **Live Preview**: Real-time watermark adjustment on the first page.
*   **Privacy First**: Runs locally or offline—your PDFs never leave your device.
*   **Full Control**: Adjust **Opacity**, **Rotation**, **Scale**, and **Position**.
*   **Flexible**: Apply to *All Pages*, *First Page*, or a *Custom Range*.
*   **Vibe UI**: Clean Light Blue & White aesthetic.
*   **Mobile Ready**: Run locally and access via phone on WiFi, or use Pydroid 3 for fully offline Android usage.

## 🚀 Quick Start

### Prerequisites
*   Python 3.9+

### Installation
1.  **Clone the repository:**
    ```bash
    git clone https://github.com/yourusername/pdf-vibe-watermarker.git
    cd pdf-vibe-watermarker
    ```

2.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the App:**
    ```bash
    streamlit run app.py
    ```

## 🛠️ Tech Stack
*   **Streamlit**: For the interactive web UI.
*   **PyMuPDF (fitz)**: High-performance PDF handling.
*   **Pillow (PIL)**: Image processing.
